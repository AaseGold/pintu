# 拼了个图

H5 拼图游戏。可直接打开 `index.html` 游玩；线上账号、图片上传和排行榜由 `server/` 中的服务提供。

当前版本：`v0.4`。版本号以根目录的 `VERSION` 为准；普通改动递增第三位修订号，推送线上发布时才递增第二位发布版本。

- 打开即玩，游客成绩先保存在本机；需要上榜或换设备时再绑定账号
- 绑定方式支持手机验证码、QQ 登录；微信账号登录入口暂未开通
- 绑定后会把本机成绩去重同步到云端，并显示云端玩家名称
- 各难度排行榜展示云端最快 50 条成绩；游客每个难度的最新成绩固定显示为待入库，登录后自动上传
- 支持快捷图库、风景图库和本地图片上传
- 支持 2×2、3×3、4×4 三档难度
- 点击两块拼图即可互换
- 包含计步、计时、编号提示、重新打乱和完成页
- 使用浏览器本地存储保存上次难度和各难度排行榜


## 版本管理

- 普通改动：运行 `node scripts/bump-version.mjs`，例如 `v0.2` 自动变为 `v0.2.1`，下一次变为 `v0.2.2`
- 线上发布：运行 `node scripts/bump-version.mjs --release`，例如 `v0.2.2` 发布后变为 `v0.3`
- 指定主版本：运行 `node scripts/bump-version.mjs 1.0`，仅在产品负责人明确要求时使用
- 脚本会同时更新 `VERSION`、README 和页面中的版本号
- 历史版本与对应提交见 [`CHANGELOG.md`](CHANGELOG.md)
