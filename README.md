# 拼了个图

纯前端 H5 拼图游戏，无需安装依赖。直接用浏览器打开 `index.html` 即可游玩。

当前版本：`v0.2`。版本号以根目录的 `VERSION` 为准；普通改动自动递增小版本，只有明确指定时才调整大版本。

- 首次访问会随机生成并保存本机玩家名，后续访问继续使用；点击顶部名字可改名
- 支持快捷图库、风景图库和本地图片上传
- 支持 2×2、3×3、4×4 三档难度
- 点击两块拼图即可互换
- 包含计步、计时、编号提示、重新打乱和完成页
- 使用浏览器本地存储保存上次难度和各难度排行榜


## 版本管理

- 普通改动：运行 `node scripts/bump-version.mjs`，例如 `v0.1` 自动变为 `v0.2`
- 指定版本：运行 `node scripts/bump-version.mjs 1.0`，仅在产品负责人明确要求时使用
- 脚本会同时更新 `VERSION`、README 和页面中的版本号
