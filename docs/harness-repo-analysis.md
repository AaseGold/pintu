# 项目整体认知报告 — 拼图时光

## 1. 项目概述

「拼图时光」是一个纯前端 H5 拼图小游戏。项目只保留一个正式入口：根目录的 `index.html`。

## 2. 技术栈与运行方式

- 原生 HTML、内联 CSS 和原生 JavaScript。
- 无框架、无构建工具、无运行时依赖。
- 直接用浏览器打开 `index.html` 即可游玩。
- 使用浏览器 `localStorage` 保存上次选择的难度和本地排行榜。

## 3. 目录结构

```text
pintu1/
├─ index.html            # 唯一正式入口（增强版）
├─ hanfu-default.png     # 快捷图库图片
├─ mountain-default.png  # 快捷图库图片
├─ seasons-default.webp  # 快捷图库图片
├─ README.md
└─ docs/
```

## 4. 主要功能

- 快捷图库、风景图库和本地图片上传。
- 2×2、3×3、4×4 三档难度。
- 点击两块拼图互换位置。
- 计步、计时、编号提示、重新打乱和完成页。
- 按难度保存本地前五名成绩。

## 5. 外部依赖与风险

- 风景图库仍引用第三方图片 URL，存在失效、防盗链和授权风险，上线前建议改成本地且具有使用授权的图片。
- 排行榜只保存在当前浏览器中，不是多人共享排行榜。
- 当前仓库尚无首次 Git 提交和远程仓库。

## 6. 部署形态

项目属于纯静态站点，可部署到 Vercel、GitHub Pages、Netlify、Cloudflare Pages 或对象存储静态网站服务，无需配置启动命令、后端服务或数据库。
